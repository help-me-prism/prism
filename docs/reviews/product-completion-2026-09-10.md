## 실측과 검증

설치된 Codex CLI 0.153.4, gpt-5.6-luna, low effort. 동일한 두 문장/1,834자 프롬프트를 각각 1회 실행했다. 두 실행 모두 번역 구조·원문 보존 검사 2/2, 도구 호출 없음.

| 실행 환경 | 전체 입력 | 캐시 입력 | 출력 | 시간 |
|---|---:|---:|---:|---:|
| 기존 일회성 환경 | 14,918 | 11,008 | 62 | 6.137초 |
| 전용 지침/도구 축소 | 8,128 | 1,792 | 59 | 5.130초 |

총 입력은 약 45.5% 감소했으나 캐시 조건은 동일하지 않다. 캐시 제외 입력은 오히려 3,910→6,336이므로 비용 절감률이나 평균 지연 개선의 증거로 사용하지 않는다. 설치별 전역 설정도 달라질 수 있다. 계측 원본은 로컬 `tmp/cli-task-check/measurement.json`에 있다. 이 표본은 의미·문체 품질을 승인하는 검사가 아니다.

적용한 Codex 설정은 [공식 설정 문서](https://learn.chatgpt.com/docs/config-file/config-reference), 문맥 정리는 [공식 app-server 프로토콜](https://learn.chatgpt.com/docs/app-server)과 설치된 CLI가 생성한 타입을 확인했다. 프로토콜 fixture에서 비동기 시작/완료·실패·사용량·취소 ID·요약 비노출을 검사했다. 실제 장기 대화의 압축 품질은 아직 사용자 검토 대상이다. Claude 변경은 설치된 CLI의 도움말과 인수 전달 검사로 확인했으며 이번 비교 실측은 Codex만 수행했다.

자동 검사: build, 전체 core, Product UI, Notes UI. 새 회귀 검사는 원본/다른 페이지 보존 재번역, 실패/취소, 재실행 초안/답변 저장 표시, 무료 정리, 명시적 이해 상태, 손상 대화 파일 보존, CLI shim, 문맥 정리 프로토콜, 중복 AI 작업을 포함한다. npm audit의 운영 의존성 발견 취약점 0건.

## 그대로 유지한 설계와 출시 잔여 조건

- 논문 전체를 매 질문에 보내지 않는다. 로컬 발췌와 명시적 근거를 사용한다. **턴 사이 동일 근거의 전송 생략은 아직 구현하지 않았다.** CLI 자동 압축 직후 원문이 요약에서 사라질 수 있어, 현재는 필요한 근거를 재전송한다. 완전한 생략에는 원문 재조회 도구·컨텍스트 리비전 검증이 추가로 필요하다.
- 이미지 원본은 보존·전송한다. **자동 저해상도 변환은 아직 적용하지 않았다.** 작은 축·수식·표 글자의 판독성 검증 전에는 해상도를 낮추지 않는다. 현행 이미지 개수/파일/픽셀 제한과 실제 사용량 기록을 유지한다.
- 사용자 CLI 인증·전역 설정을 완전히 분리한 실행 환경은 아니다. 위에서 명시한 지침/도구만 줄였다. 전역 플러그인·관리 정책별 비용을 모두 제거했다고 주장하지 않는다.
- 대화 저장은 여전히 전체 snapshot 방식이다. 이번에는 보존·복구와 용량 한도를 개선했다. 매우 큰 보관 이력의 부분 저장/검색 색인은 별도 성능 작업으로 남는다.
- 그래프·구조 맵·템플릿·원문/번역 비교·피겨 캡처는 유지한다. 인용을 자동으로 ‘확장함’ 관계로 바꾸거나, 읽음 처리 때 자동 과금하는 동작은 복원하지 않는다.
- Mac 패키징 CI와 실제 Mac 사용성은 별개다. Mac 실기기 설치/CLI 연결, 배포 서명·공증·자동 업데이트, 공개 출시 승인은 아직 완료되지 않았다. Windows 검토용 portable 빌드는 공개 배포판이 아니다.

## 한 번에 받을 사람 피드백

통과한 논문 선택 해제·설정 사용 기록 찾기는 다시 검사하지 않아도 된다. 아래 세 가지를 같은 검토 빌드에서 확인하면 된다. 오류가 나면 논문/페이지/행동/기대한 결과/실제 결과만 기록한다.

1. **읽기·번역:** 익숙한 논문에서 현재 페이지 재번역 1회. 부정·수치·단위·주장 강도와 작은 피겨 글자를 원문과 비교한다. ‘정확함/의미가 바뀜/읽기 불편’으로 평가한다. 번역이 없는 곳을 번역된 것처럼 보여주는지도 확인한다.
2. **지식 정리:** 논문 노트에서 ‘아직 모르겠음 · 메모’ 작성→‘이해함’ 표시→읽음 상태에서 연결 후보 생성→승인 전 내용 확인. 버튼 의미와 상태의 차이를 설명 없이 이해할 수 있는지 평가한다. 연결 후보 생성만 AI 사용.
3. **대화 연속성:** 길어진 Codex 대화에서 문맥 정리 1회 후 앞서 논의한 방법/한계 질문. 중요한 조건을 잊었는지 판단한다. 화면 대화 기록은 그대로 남아야 한다. 문맥 정리와 후속 질문은 AI 사용.

Mac 기기가 있으면 이후 별도 설치 검토에 사용 가능 여부만 알려 주면 된다. 서명 자격증명 같은 민감한 값을 대화에 붙여넣을 필요는 없다.
