# 첫 페이지 피겨 오탐과 번역 표시 수정 — 2026-09-11

사용자 스크린샷의 CRISPR 논문 첫 페이지를 같은 PDF와 사용자 번역 캐시의 사본으로 재현했다. 기존 25/26 완료 표시는 저장된 번역 수였고, 페이지 대부분을 덮은 잘못된 피겨 이미지 때문에 실제 본문이 숨겨졌다. 이전 대표 페이지 검사에서 놓친 문제다.

## 원인과 수정

- HHMI 로고·여백 장식선의 PDF 벡터 경계를 합치면 504×702pt 사각형이 생겼다. 그래픽 사각형과 실제 본문 글자 영역의 교차를 검사해 이 후보를 제외한다. 빈 열 간격이나 짧은 축 라벨은 본문 교차로 세지 않는다.
- PDF 클리핑 전용 경로는 그림의 근거에서 제외한다. 추정한 LaTeX 피겨와 캡션 확장에도 본문 교차 검사를 적용한다.
- 번역 렌더러에서도 다시 검사하고, 저장된 번역문을 피겨 안이라는 이유만으로 버리지 않도록 했다. 기존 캐시도 새 앱에서 다시 표시된다.
- 원문 보존 문단은 일부 캐시가 재검증을 통과하지 못해도 한 영역으로 묶는다. 저자·소속이 잘린 조각으로 중복 표시되는 것을 방지한다. 상단 로고를 자르지 않도록 첫 글자 직전까지 여백을 보존한다.
- 수평 출판 정보와 세로 원고 표시가 같은 문단이 되지 않도록 텍스트 방향이 바뀌면 분리한다. 기본 좌표 계산에도 회전을 반영한다.
- 초록 앞 저자·소속과 별표가 있는 저자 이름, 출판일은 원문 메타데이터로 보존한다. 인명 조각을 한국어로 번역하지 않았다는 이유로 실패시키지 않는다.
- `One-Sentence Summary:`와 이어지는 본문을 분리한다. `1. Introduction`, `3.3. Geometric Details…`의 마지막 마침표를 문장 종결로 오인하거나 짧은 도표 조각으로 분류하던 경우를 수정했다.
- Attention 시각화의 회전된 축 단어, Arti-PG 도식의 함수 호출 코드와 서로 떨어진 패널 제목을 산문에서 제외한다. 정상 피겨가 본문 오탐 방지 규칙 때문에 사라지는 회귀를 막는다.
- `September 14, 2015 → 2015년 9월 14일`, `past decade → 지난 10년`을 추가 숫자로 잘못 거부하던 검증을 수정했다. 다른 월이나 원문에 없는 숫자, 중복된 수치는 계속 거부한다.

## 검증 방식

- 같은 11개 PDF, 총 173쪽에서 그래픽 후보와 본문 교차를 검사했다.
- 실제 PDF 경로·텍스트 조각을 담은 `figure-prose-corpus.json` 및 회귀 테스트를 추가했다. CRISPR 첫 페이지의 큰 오탐 제거와 생물학 그림, Transformer 구조, Attention 시각화, 코드 도식의 보존을 함께 확인한다.
- 11개 문서의 첫 페이지를 앱에서 열고 새 번역 또는 기존 캐시 복구를 실행했다. 저장 개수뿐 아니라 화면에 실제로 표시되는 한국어와 원문 대기 문장을 검사했다.
- 사용자 원본 라이브러리·설정·번역 캐시는 수정하지 않았다. 검사는 `tmp/translation-review/library` 사본과 별도 앱 프로필에서 수행했다.

표·알고리즘·피겨 내부를 한국어로 다시 그리는 기능은 아니다. 본문과 캡션을 번역하고 그래픽·수식은 원문 형태로 보존한다. 스캔 PDF의 OCR 기능은 포함하지 않는다.

## DMG 실행 확인

읽기 전용으로 마운트한 새 DMG의 `Prism.app`을 별도 프로필로 실행했다. CRISPR 첫 페이지의 자동 피겨 버튼은 0개이고, 원문/번역 비교 화면에 한국어 제목과 초록이 표시된다. 정상 생물학 그림과 Attention 시각화·Arti-PG 코드 도식은 자동 피겨로 유지된다.

화면과 실행 결과는 `tmp/translation-review/fix2-crispr-comparison.png`, `first-pages-results.json`, `followup-layout-audit.json`, `followup-diagram-results.json` 등에 남겼다. 본문 겹침 검사와 원문 이미지 캔버스 확인도 수행했다. 모든 출판 형식이나 번역 의미 정확성을 보증하는 결과는 아니며, 손상된 PDF 글자·수식은 원문으로 남을 수 있다.
