# Round 20: 검색 발췌와 노트 연결 전환

2026-09-10. `@oai/sky`로 격리된 Windows persona 앱의 실제 화면을 확인했다. 코드와 fixture는 수정하지 않았다. CLI 호출·모델 다운로드·의미 검색을 실행하지 않았다. 결과 관련성이나 모델 도입 여부를 평가하는 기록이 아니다.

## 첫 빌드: 여러 줄 결과 레이아웃

PID 19564 / port 9351에서 의미 검색을 끄고 `기공 비율`, `conductivity`, `1%`로 본문 검색했다.

- 제목 13px·최대 2줄, 발췌 12px·최대 3줄이 실제 결과 행에 적용됐다. 일반 노트 트리는 기존의 작은 행으로 유지됐다.
- 라이트·다크에서 영문 제목과 발췌가 읽혔고 행 겹침은 보이지 않았다. 긴 한국어 주장 제목은 2줄 말줄임으로 표시되어 트리 밖으로 넘치지 않았다. `engineering-foamed-concrete`도 두 줄로 표시됐다.
- `conductivity` 결과를 열어 `Air-filled pores reduce…`가 실제 노트 본문과 대응함을 확인했다.
- 그러나 `기공 비율` 결과에는 `(3번 물어봄) 내가 주목한 것 근거1…`, `PDF 원문 열기…어디서 나왔나…` 같은 자동 구간 문구가 먼저 나왔다. 영어 결과도 제목을 발췌에서 반복했다. 레이아웃 개선은 확인했지만 이 빌드의 발췌 선택은 반려했다.

이 단계의 로컬 증거는 `tmp/ui/round20-search-korean-light.png`, `round20-search-english-light.png`, `round20-search-open-note.png`, `round20-search-english-dark.png`, `round20-search-long-title-dark.png`이다.

## 최종 빌드: 실제 정의·본문 중심 발췌

PID 23288 / port 9351 재시작 후 다크 테마, 의미 검색 꺼짐 상태를 유지했다. 각 검색어를 입력하고 Enter로 본문 검색했다.

- `기공 비율`: 논문 결과가 `근거1 (p.11) — Fig 12…비율은…`이라는 실제 정의 문장으로 시작했다. 개념 결과도 `For one type of FRFC in Fig 12, the proportion…`이라는 원문 근거 문장으로 시작했다. 이전의 자동 안내·관계 구간 잡문구가 앞을 차지하는 문제는 이 두 결과에서 해소됐다.
- `기공 형상 계수` 노트를 열어 검색 발췌가 p.11 문장176 근거 카드의 원문과 일치함을 확인했다. 3줄 결과 행에는 긴 정의의 분모 끝까지 나오지 않는다. 어떤 근거인지 판단하고 노트를 열 수 있지만, 결과 행만으로 정의 전체를 확인할 수 있다는 뜻은 아니다.
- `conductivity`: Enter 검색 이후 발췌가 제목 반복 없이 `Air-filled pores reduce the effective thermal conductivity of a dry solid by interrupting…`으로 시작했다. 노트를 열어 실제 첫 문장과 대조했다.
- 입력 중 로컬 필터의 미리보기에서는 제목 반복이 여전히 보였다. 최종 본문 검색에서는 해소됐으므로 두 상태의 발췌 품질을 구분해야 한다.

최종 빌드에서 이 두 본문 검색의 발췌 개선을 제한적으로 확인했다. 모든 노트·질문·발췌 유형이 검증된 것은 아니다.

## 연결 패널 전환

`기공 형상 계수`에서 `engineering-foamed-concrete`로 갔다가 돌아오는 왕복을 두 번 수행했다. 첫 왕복은 직접 연결, 두 번째 왕복은 간접 연결을 켠 상태였다.

- 개념 노트는 개념 중심과 논문 연결, 논문 노트는 논문 중심과 개념·주장 연결로 표시됐다. 확인한 전환 직후 화면에 이전 노트가 잘못 중심으로 남는 현상은 보이지 않았다.
- 간접 연결을 켠 개념 노트에서는 추가 점과 `간접 연결 1개`가 표시됐다. 논문으로 이동했을 때는 `확인한 간접 연결이 없습니다`로 바뀌고, 다시 개념으로 돌아오면 1개로 돌아왔다.
- 처음 개념 노트를 불러올 때는 잠시 본문 로딩 및 빈 그래프 영역이 보였다. 이후 올바른 연결이 표시됐다. 이를 모든 로딩 깜빡임이 없어졌다는 판정으로 확대하지 않는다.
- 연결이 없는 `Heat transport through porous solids`를 열자 해당 노트의 점 하나와 연결 없음 상태가 표시됐다. 이전 기공·논문 연결이 남지 않았다.

입력 뒤의 개별 스크린샷 관찰이며 연속 영상이나 프레임 계측은 아니다. 순간적인 깜빡임, 지연된 비동기 응답의 모든 경쟁 조건, 볼트 변경 중 전환은 검증하지 않았다. 인위적 지연도 주입하지 않았다.

## 배포 브랜치 반영

이 검토에서 확인한 발췌·검색 결과 배치·연결 조회 보호를 `codex/product-reader`에 반영했다. 별도의 깨끗한 체크아웃에서 전체 core 검사와 product UI 자동 검사가 통과했다(`round20-stable-core.log`, `round20-stable-ui.log`). 학습 모델·다운로드 UI·ONNX 의존성은 포함하지 않았다. 문자 특징을 의미 벡터처럼 취급하던 기존 검색은 제거하고 제목·본문 검색으로 표시한다. 다국어 검색 실험은 로컬 `codex/note-search-lab`에 보존했다.
