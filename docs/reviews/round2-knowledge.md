# Round 2 — 실제 화면 기반 지식 연결 검토

2026-09-09. 역할: Obsidian을 사용하는 생물학 박사과정 학생. 사람이 참여한 사용자 연구가 아니라 에이전트가 Windows 앱 화면을 조작한 사용성 검토다. 기존 isolated persona vault와 실제 Luna 답변을 사용했으며 추가 AI 호출은 하지 않았다. 생물학 논문 내용 검증은 이 세션 범위에 포함하지 않았다.

## 실제 수행과 결과

1. Flow Matching 논문을 읽는 Reader에서 노트 탐색을 클릭했다. 별도 Notes 창이 열리고 현재 논문의 노트가 바로 선택됐다. 이전 라운드의 빈 화면 문제가 재현되지 않았다.
2. 종전 실제 AI 답변까지 중앙 편집 영역을 두 번 스크롤했다. `5줄 펼치기`를 한 번 클릭하자 질문과 3개 답변 문장, 모델·날짜가 읽을 수 있게 나타났다. 이전 비활성 접힘 표시 문제는 해소됐다. [화면](../../tmp/ui/round2/knowledge-answer-expanded.png)
3. 기존 `시뮬레이션 없는 학습` 개념을 열었다. 이전 세션에서 쓴 ODE 학습/생성의 구분 문장이 그대로 남았고 논문 링크 및 연결 그래프가 표시됐다.
4. 질문 옆 +를 누르고 유형 설명을 읽은 뒤 `세포 분화 경로에도 시뮬레이션 없는 학습을 적용할 수 있을까?`라는 질문을 만들었다. 한 번 저장 후 질문 노트가 선택되고 목록에 추가됐다.
5. 질문 속성의 `관계 추가`를 눌렀지만 가능한 관계가 없다는 알림이 나타났다. 질문에서 만들 수 없는 동작을 보여주는 문제를 확인했다.
6. 출처 논문 탭 → 속성 → 관계 추가 → 질문 제기 → 방금 만든 질문을 선택했다. 저장 알림과 속성의 관계, 그래프의 새 연결이 나타났다. 기존의 점선 본문 링크와 새 관계가 구분됐다. [화면](../../tmp/ui/round2/knowledge-question-relation.png)
7. 전체 지식 그래프에서 질문 노드를 클릭하고 `노트 열기`로 이동했다. 질문의 받은 관계를 클릭하면 출처 논문 노트가 열렸고, `리더에서 열기`로 PDF에 돌아갔다. [그래프 화면](../../tmp/ui/round2/knowledge-graph-selection.png)

## 관찰 뒤 추가 수정

- 의미 있는 관계가 `속성` 안에 숨겨져 있었다. 노트 상단에 `관계`를 추가하고 질문에서는 `답 연결`을 직접 제공한다. 불가능한 질문의 일반 관계 추가 버튼은 숨긴다. 관계 선택기는 `이 노트 → 관계 의미 → 대상 노트` 방향을 명시한다.
- 전체 그래프 자체의 상세 패널 옆에 내용 없는 연결 패널이 330px를 더 차지했다. 그래프·정리 화면에서는 외부 연결 패널을 숨겨 작업 영역을 확보한다.
- 하단 도구가 단어 중간에서 두 줄로 접혔다. 버튼은 줄바꿈하지 않고 도구 행 전체가 다음 줄로 이동하게 변경했다. 상단 제목과 도구도 행을 분리해 긴 연구 질문을 읽기 쉽게 한다.
- 무료 결정적 정리 중에 AI 정리 버튼이 `AI 정리 중`으로 표시되는 잘못된 문구를 `정리 중`으로 수정했다. 읽음 표시·노트 열기로 모델을 호출하지 않는다.

위 추가 수정은 코드·타입 검사까지 완료했으며, 같은 수정 빌드에서의 화면 재검증은 별도 후속 검증이 필요하다.

제목에서 물음표가 사라진 현상도 확인했다. 이후 파일 이름만 정제하고 표시 제목·frontmatter·본문 제목의 과학 기호와 문장 부호는 보존하도록 수정했다. 한국어, 경로 구분자, Windows 예약 파일명 회귀 검사가 통과했다.

## 남은 사용성 과제

- 저장한 대화까지 스크롤이 긴 문제에 `메모 보기` 바로가기를 추가했다. 접힌 상위 제목도 펼쳐 이동한다. 실제 화면 재검증은 아직 필요하다.
- 전체 그래프의 글자 외곽선과 잘린 긴 제목이 읽기를 방해한다. 선택 패널에서 전체 제목은 확인 가능했다.
- Markdown 편집 중 내부 경로가 포함된 위키 링크가 그대로 보인다. Obsidian 사용자는 이해할 수 있지만 처음 사용하는 학생에게는 표시 제목 중심의 읽기 상태가 더 쉽다.
- 이 검토는 질문과 출처 연결을 확인했다. 실제 생물학 논문 근거의 정확성, 동시 외부 편집 장시간 사용, macOS 실사용을 입증하지 않는다.

## 후속 회귀 검사

최신 빌드에서 Notes UI smoke 전체 통과. 접힘 요약 버튼 펼치기와 Markdown 동일성, 상단 관계 생성과 조건 불일치 경고, 근거 메모→주장, 외부 파일 변경 반영/충돌, Obsidian 이동, 검색과 양식 접근을 검증했다. 두 번의 초기 실패는 변경한 한국어 버튼/검색 표시를 테스트가 예전 이름으로 찾은 원인이었고 선택자를 갱신했다.

스크린샷을 추가 검토해 속성 갱신 후 YAML이 본문에 드러나는 문제를 발견했다. 메타데이터 길이가 늘 때 기존 절대 커서가 YAML 안으로 이동하는 원인이었다. 본문 기준 커서 위치를 보존하도록 수정하고 회귀 검사를 추가했다. 이 마지막 수정은 TypeScript 통과 상태이며, 전체 UI 재검사는 부모 에이전트의 다음 통합 검증에 포함한다.
