# 번역 품질 개선 및 검증 — 2026-09-11

후속 사용자 재현 사례와 최신 DMG 검증은 [첫 페이지 피겨 오탐 수정 기록](translation-followup-2026-09-11.md)을 참조한다.

브랜치: `jinsu-optimize`. 로컬 라이브러리 8개 PDF를 사본으로 복사하고 공개 PDF 3개를 추가해 검사했다. 원래 라이브러리, 설정, 번역 캐시는 수정하지 않았다. 커밋과 push는 하지 않았다.

## 수정한 동작

- PDF 표는 LaTeX 원본 유무와 관계없이 좌표·숫자 행·캡션을 근거로 판별한다. 셀·숫자·행·열·선은 원문 이미지로 보존하고 캡션은 별도로 번역한다. 프롬프트처럼 문장으로 이루어진 표도 원형을 유지한다. 먼저 연결된 표를 뒤의 다른 캡션이 빼앗지 않도록 했다.
- `Algorithm 1/2`의 의사코드는 산문 번역 대상에서 제외하고 들여쓰기·행 번호·기호를 보존한다. PDF 폰트가 이미 깨뜨린 수식은 추측해서 번역하지 않는다.
- 참고문헌 제외를 페이지 번역과 전체 번역에 똑같이 적용한다. `References and Notes`, 제목 없는 연속 번호 참고문헌, 참고문헌 이후 부록·피겨 캡션을 구별한다.
- 반복되는 여백 러닝헤드, 페이지 번호, `HHMI Author Manuscript` 등을 원문으로 유지한다. 회전된 텍스트의 실제 방향을 반영해 세로 러닝헤드를 가로 본문 영역으로 잘못 자르지 않는다.
- 번호·이름이 있는 제목과 다음 본문의 경계를 보완했다. 본문 중간에 별도 PDF 조각으로 나온 `results`는 제목으로 취급하지 않는다. 약어·소수점·글머리표·같은 줄의 복합어 하이픈도 보완했다. 실제 공학 PDF의 장비명 `JTRG-Ⅲ`에서 하이픈을 잃던 회귀 사례를 수정했다.
- 누락·잘못된 JSON·수치/수식 검증 실패는 실패한 문장만 작은 배치로 한 번 자동 재시도한다. 먼저 성공한 결과는 저장한다. 재시도에도 실패하면 완료로 숨기지 않고 원문과 경고를 표시한다.
- 원문을 그대로 반환한 영어 산문과 추가·중복된 숫자를 거부한다. `one-dimensional → 1차원`, `unity → 1`처럼 원문에 명시된 숫자 표현은 허용한다.
- 문단 분할 수정으로 ID가 바뀌어도 같은 원문의 일치하는 캐시는 재검증 후 재사용한다. 자동 번역이 켜져 있으면 부분 캐시의 미완료 본문도 이어서 처리한다. 번역 재시도 시 오래된 오류 배너를 지운다.
- 구조 판별용 기본 PDF 좌표와 글자 마스킹용 검증된 정밀 좌표를 분리했다. 정밀 글자 검증 실패가 표 판별까지 막지 않는다.

- 원문 보존 영역을 합칠 때 러닝헤드를 제외해, 다른 열의 원문까지 큰 사각형으로 잘라 중복 표시하지 않도록 했다.
- PDF 형식 피겨 미리보기 렌더링 후 임시 PDF 작업을 해제해, 논문을 반복해서 열 때 worker가 누적되지 않도록 했다.

## 검증

- TypeScript 및 production 빌드 성공.
- `node scripts/run-core-tests.mjs`: 80개 코어 테스트 스크립트 통과.
- Electron UI smoke 통과: 기본 시작·설정·참조·IME·창 상태 회귀 확인.
- 실제 PDF 조각을 사용하는 `scripts/test-translation-layout-corpus.mjs` 추가. 표 인접 관계, 로마 숫자 표, 알고리즘, 문장형 표, 참고문헌/부록, 제목 경계, 러닝헤드, 글머리표를 검사한다.
- 새 Apple Silicon DMG를 읽기 전용으로 마운트하고, 그 안의 `Prism.app`에서 대표 페이지 번역·캐시 복구·화면을 확인했다.
- 최종 대표 번역 페이지 11곳에서 번역 대기 문장 없음, 본문 블록의 실질적인 겹침·가로 넘침 없음. 글자 영역의 작은 여백 접촉은 겹침으로 세지 않고, 블록 너비의 8%를 넘는 교차를 검사했다. 표·알고리즘 원문 캔버스도 직접 확인했다.
- 두 논문을 번갈아 4회 연속 열었을 때 활성 PDF worker 수가 매번 1개로 유지되는 것을 확인했다.
- 상세 실행 기록과 화면 캡처는 `tmp/translation-review/`에 저장했다. 실제 사용자 라이브러리 대신 같은 경로 안의 사본을 사용했다.

## 사용 범위

표의 셀 문구와 알고리즘 내부를 한국어로 재조판하는 방식은 아니다. 원문 구조·수식·수치를 보존하면서 본문과 캡션을 번역한다. 원본 PDF의 글자 인코딩이 깨진 구간은 원문 이미지로 남을 수 있다. OCR이 없는 스캔 PDF의 OCR 기능은 이번 변경에 포함되지 않는다.

중력파 논문의 상단 날짜 러닝헤드에서 일부 잘림·중복 표시가 남아 있다. 본문·표의 중복 문제는 해소했지만, 출판사별 여백 재현에는 추가 개선 여지가 있다.

검증은 위 문서와 대표 페이지 기준이다. 모든 출판 형식이나 모든 번역의 의미 정확성을 보증하는 결과는 아니다. DMG는 로컬 개발 빌드이며 Developer ID 서명·공증은 포함하지 않는다.
