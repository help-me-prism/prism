# 논문 읽기 개선 · 2026-09-13

## 변경

- 논문 열기에 네이티브 PDF 드롭 추가. 파일 선택과 같은 검증·복사·중복 확인 경로를 사용한다. 첫 페이지와 PDF 제목에서 arXiv ID 또는 제목을 확인하고, arXiv 소스 응답에 실제 LaTeX 문서가 있을 때만 온라인 버전 선택을 제안한다. 불확실한 제목 일치·오프라인·PDF/HTML 응답은 제안하지 않는다. 사용자가 선택하기 전에는 가져온 PDF로 유지한다.
- 번역의 실행 여부, 완료 문장 수, 전체 문장 수, 마지막 번역 결과를 논문별로 관리한다. 이벤트 revision으로 오래된 상태를 거부하며, 다시 연 논문은 메인 프로세스의 최신 상태를 조회한다. 페이지 번역의 분모도 해당 범위로 유지한다. 취소는 실행 종료가 확인되면 반영한다.
- 전체 구조·글자 좌표 분석은 `reader-analysis.json`으로 재사용한다. PDF 내용, LaTeX/JATS 내용, PDF.js 버전, 추출기 버전이 바뀌거나 캐시가 손상되면 다시 분석한다. 이전 `anchors.json`에는 정확한 글자 좌표가 없어 처음 한 번은 새 분석이 필요하다. 이 단계 자체는 로컬 PDF 분석이다.
- 연속 수식에서 artifact 조각을 포함한 병합 영역을 제외하던 조건을 수정했다. 번역·원문 모두 같은 보존 종류를 사용하고 합쳐진 수식의 원래 anchor ID도 유지한다.
- 새 인용은 문장·수식·표·피겨·섹션·페이지별로 구분한다. 이전 대화의 `근거N` 인용 ID는 보존하며 UI에서 종류를 보여준다. 대화 전체의 번호 충돌과 기존 인용 연결도 유지한다.
- 로드된 Codex 대화의 매 턴 `thread/resume` 재호출을 제거했다. 한 app-server에서 한 번 로드한 thread는 재사용하고 서버가 종료될 때만 초기화한다. 중복 전송은 IPC 진입 시 예약하며, 실패·매우 빠른 완료 시 실행 상태가 남지 않도록 했다.
- 노트의 `$…$`, `\(…\)`, `$$…$$`, `\[…\]`를 KaTeX로 표시한다. 인라인 수식과 수식 블록은 클릭·키보드 편집 시 Markdown을 보여주고, 포커스를 잃으면 다시 렌더링한다. 보관된 Markdown은 변경하지 않는다. 저장된 수식 근거 카드도 수식으로 표시한다.
- 논문 아이콘이 긴 제목에 밀려 축소되던 현상을 고치고 저자·연도와 현재/마지막 읽은 쪽을 표시한다. 대화의 C/A 배지를 제거하고 실제 최근 질문을 두 줄 제목으로, 관련 논문과 질문 수를 보조 정보로 표시한다. 짧은 감사·계속 요청은 기존 질문 제목을 덮지 않는다. 기존 대화에도 적용한다.
- 라이브러리 카드의 `width: 100%`와 좌우 여백이 합쳐져 잘리던 CSS 우선순위를 수정했다. 긴 폴더명은 카드 안에서 말줄임하고 전체 경로는 툴팁으로 확인한다.
- 원문과 번역문 모두 오른쪽 마우스 드래그 및 캡처 모드로 영역을 선택할 수 있다. 원문은 PDF 영역을 고해상도로 다시 렌더링하고, 번역문은 Electron의 해당 창 캡처로 보이는 한글·그림을 저장한다. 선택 테두리와 조작 UI를 제외하며, 재배치된 그림은 픽셀 비율로 원문 좌표에 연결하고 본문은 해당 원문 블록에 연결한다. 페이지보다 길어진 재배치 화면의 아래쪽도 선택할 수 있다. 단순 우클릭의 메모 동작은 유지한다.

## 복합 피겨 원인

TnpB PDF의 2쪽에는 5천 개가 넘는 벡터 경로와 작은 비트맵 패널이 있다. 기존 경계 추출은 Form XObject의 암묵적 좌표 변환/복원을 놓쳤고, 처음 1,500개 경로만 처리했다. 페이지 테두리 선이 패널들을 페이지 크기의 한 영역으로 연결하면 이 영역이 배경으로 제외되는 문제도 있었다. 작은 래스터를 합치기 전에 제거하여 젤 이미지 등의 일부가 누락될 수 있었다.

그래픽 상태와 Form 좌표를 함께 처리하고, 페이지 전체에 걸친 테두리 선을 제외하며, 전체 벡터와 작은 래스터를 처리한다. 캡션의 열과 본문 경계를 이용해 떨어진 패널을 하나의 피겨로 모은다. 피겨 내부에서 추출된 축·패널 글자는 번역 캐시가 있어도 다시 배치하지 않는다. 배율 변경 중 이전 좌표가 새 캔버스에 적용되는 화면도 방지했다. 논문 이름이나 DOI를 검사하는 예외 처리는 없다.

- `node scripts/test-reader-regressions-ui.mjs <PDF 경로>`: 실제 TnpB PDF와 기존 번역의 복사본을 격리한 볼트에서 확인. 원문·번역 2쪽에서 복합 피겨 2개와 녹색 영역, native 우클릭 드래그 PNG, native PDF 드롭/원문 선택, 논문별 진행률, 분석 캐시 재사용, 수식 표시/클릭 편집/Markdown 보존을 검증했다.
- Codex thread writer는 실제 app-server 클래스에 주입한 프로토콜 모의 응답으로 재현·검증했다. 검증 중 유료 모델 요청을 실행하지 않았다.

자동 피겨 경계는 PDF의 그래픽·캡션 정보에 의존한다. 텍스트가 없는 스캔 등 자동 인식이 어려운 경우에도 우클릭 드래그로 정확한 범위를 지정할 수 있다.
