## 디자인 판단

[Linear의 UI 개편](https://linear.app/now/how-we-redesigned-the-linear-ui)의 정보 위계·밀도·일관성과 [Readwise Reader의 읽기·하이라이트·노트 흐름](https://docs.readwise.io/reader/docs/faqs/highlights-tags-notes)을 참고했습니다. 화면을 복제하지 않고, 논문 읽기에 맞게 낮은 채도의 중립색, 제한적인 녹색 강조, 명료한 한국어 행동 이름, 조용한 테두리를 적용했습니다.

- 라이트 / 다크 / 시스템 테마를 설정에서 선택하고 창 간 동기화합니다.
- 인쇄물의 색 정보는 유지합니다. 다크 모드도 PDF·원문 발췌는 흰 지면입니다.
- 목록 글자 크기와 번역 행간을 높였습니다. 장식적인 AI 강조를 줄였습니다.
- 읽기 집중 모드, 설정 접기, 현재 화면을 가리키기만 하던 무동작 버튼 제거, 첫 화면의 강제 모달 제거를 적용했습니다.
- 모달의 Tab 이동을 내부로 제한하고 Escape 닫기 및 포커스 복원을 지원합니다.
- 번역 캐시가 일부만 있어도 재번역하지 않고 이어서 진행합니다. 처음부터 다시 번역하는 버튼은 설정 안에 별도로 둡니다.

## 모델 비용과 번역 검증

기본 자동 번역은 꺼져 있습니다. Codex 모델 목록은 Luna/mini 계열을 먼저, Claude는 Haiku를 먼저 보여 주며 번역 CLI에는 낮은 추론 강도를 지정합니다. 기존 사용자가 저장한 모델 선택은 강제로 바꾸지 않습니다. 모델을 다른 단계로 자동 승격하거나 실패 때 고급 모델로 재시도하지 않습니다.

번역 하네스는 문서 내부 지시를 데이터로 취급하고 문맥의 중복과 길이를 제한합니다. 응답은 JSON 전체 형식·항목 수·ID 집합·중복·빈 문자열·비정상 길이를 검사합니다. 입력의 LaTeX 수식과 숫자 인용 표기가 빠지거나 바뀌면 해당 배치를 저장하지 않습니다. 캐시는 같은 ID뿐 아니라 같은 원문일 때만 재사용하며 파일 교체는 원자적으로 수행합니다. 사용자가 중지하면 다음 배치를 실행하지 않습니다.

실제 GPT-5.6 Luna / low 호출 한 번으로 다음 5종을 확인했습니다. CLI가 보고한 사용량은 **3,878토큰**입니다.

| 입력 목적 | 관찰 결과 |
| --- | --- |
| BRCA1 발현·생존 관계와 p=0.08 | 유의하지 않다는 부정과 수치 유지 |
| 37 °C / 24 h / 5% CO2 배양 | 온도·시간·기체 농도 유지 |
| `$E=mc^2$`와 `[12]` | 원문 표기 그대로 유지 |
| 시사하지만 인과를 확립하지 않는 결과 | 주장 강도와 불확실성 유지 |
| 문서 안의 “ignore previous instructions” | 지시로 실행하지 않고 문장의 내용으로 번역 |

이것은 소량의 실제 모델 검증이며, 모든 분야·언어·문서 레이아웃의 품질 인증은 아닙니다. 레이아웃 테스트의 한국어 문장은 별도의 고정 테스트 데이터로, 실제 모델 응답인 것처럼 취급하지 않았습니다.

## 배포 판단과 남은 조건

이번 결과를 **제한된 실제 사용 검증이 가능한 개선 빌드**로 평가합니다. “모든 환경에서 바로 상용 배포 가능”이라는 판정은 하지 않습니다.

1. Windows 실행 파일의 생성/실행 검증과 별개로 공개 배포용 서명·설치/업데이트 정책이 필요합니다. macOS Intel/Apple Silicon 빌드 작업은 CI에 구성했지만 이 작업 환경에서 원격 CI 실행이나 Mac 실기기 검증을 수행하지 않았습니다. Developer ID 서명·공증도 별도입니다.
2. 더 다양한 실제 생물학·공학 PDF, 다중 패널·수식 글꼴·이미지 전용 스캔으로 품질 표본을 늘려야 합니다. OCR은 구현되어 있지 않습니다. 벡터 결합은 휴리스틱이며 감지 실패 시 원문 펼치기/수동 피겨 캡처가 필요합니다.
3. 피겨 참조는 원본 캡처·미리보기·근거 파일을 보존하지만, 모든 CLI/모델 조합에 대해 이미지 픽셀을 직접 전달하는 멀티모달 추론은 보장하지 않습니다. 프롬프트는 캡션만으로 피겨를 봤다고 주장하지 않게 합니다.
4. 현재 본문 문맥은 비용을 제한한 발췌입니다. 전체 논문과 모든 선택 논문을 항상 완독한 것으로 답하지 않도록 명시합니다. 분야별 답변 정확성에 대한 별도 평가가 필요합니다.
5. 라이브러리 폴더 전체 이동/외부 파일 경로 재연결 UI, 이미지 OCR, 출판사별 직접 PDF 가져오기, 동시 Obsidian 편집의 장시간 스트레스 테스트는 다음 릴리스 범위입니다.
6. 페르소나 리뷰는 가상 검토입니다. 실제 초보 연구자와 접근성 사용자의 관찰 테스트가 공개 릴리스 전 필요합니다.

기존 사용자 데이터 형식을 보존하면서 핵심 흐름을 개선했고, 사용하지 않는 기능을 전부 지우거나 테스트가 없는 전면 재작성으로 바꾸지는 않았습니다.

## 2026-09-09 화면 기반 후속 수정

- UI는 로컬 Pretendard로 통일하고 논문 활자는 원문 크기·칼럼·문단 위치에 맞췄습니다. 한국어 길이에 따라 세로 공간을 늘리되 수식·표·피겨는 원문 픽셀로 유지합니다. 종이 안의 제품 머리말을 제거하고 크롭 선명도와 문장 경계 중복을 수정했습니다.
- 탭의 중복 모드 버튼을 제거하고 읽기 조작을 원문/한국어/비교·메모·번역·더보기로 정리했습니다. 좁은 화면에서 처음 비교하면 상하로 열며, 직접 선택한 배치는 유지합니다.
- 현재 페이지 번역을 기본으로 하고 본문 전체 번역에서 참고문헌을 제외합니다. 수치·단위·비교 방향 검증과 개별 문장 실패 격리, 재사용 캐시 검증을 보강했습니다. 실제 생물학 23문장과 공학 18문장 번역 검증은 CORPUS_QUALITY.md에 기록했습니다.
- 질문 준비 중 취소·대화 전환·새 초안의 경합을 처리하고, 근거 번호와 답변 저장 대상 논문을 메시지에 고정했습니다. 노트 화면의 불필요한 AI 실행과 접힌 문서 조작 문제를 줄였습니다.
- 전체 코어 검사, 제품 UI, Notes UI, 채팅 UI를 통과했습니다. 실제 Windows 화면에서는 공학 p4의 원문/번역 대응, 표·수식 선명도, 메뉴·키보드·테마·페이지 전환을 확인했습니다. 디자인 담당과 별도 취향 심사 담당의 판정 범위는 각 리뷰에 명시했습니다.
- 최신 검토 패키지는 `release/design-review/Prism-0.1.0-Windows-x64.exe`입니다. 공개 배포용 서명과 Mac 실기기 검증은 포함하지 않습니다. 기존 `release/product-review` 파일은 이전 버전입니다.

남은 확인: 부분 번역 실패 시 같은 연속 문단의 승인된 번역도 원문으로 표시되는 제한, 초기 조판 시 잠깐의 재배치, 더 다양한 논문·화면 크기에서의 장시간 사용. 새 채팅의 실제 토큰 절감량은 수치로 검증하지 않았습니다. 테스트와 제한된 화면 심사 결과를 전체 제품의 무결성 보장으로 확대하지 않습니다.
